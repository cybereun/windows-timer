윈도우 타이머

WindowsTimer.exe를 두 번 클릭해 바로 실행하세요. 설치, 로그인, 인터넷 연결은 필요 없습니다.
Noto Sans KR 글꼴과 3D 그림이 실행 파일 안에 들어 있습니다.

1. 종료 또는 재부팅을 선택합니다.
2. 몇 분 뒤 실행하거나 날짜와 시간을 지정합니다.
3. 빠른 시간 버튼으로 간편하게 고르거나 + / − 버튼으로 분을 조절합니다.
4. 예약 시작을 누르면 남은 시간이 표시됩니다. 실행 전에 60초 알림이 나타납니다.
5. 예약 중 언제든 예약 취소 또는 10분 연장을 누를 수 있습니다.

창의 닫기 버튼은 앱을 트레이로 숨깁니다. 트레이 아이콘을 두 번 클릭해 다시 엽니다.
트레이 메뉴의 앱 종료는 예약을 취소한다는 확인을 표시합니다.
예약은 앱이 실행 중일 때만 유지됩니다. PC가 꺼져 있거나 절전 중에는 실행되지 않습니다.
절전에서 깨어난 시각에 예약이 임박했거나 이미 지났다면 60초 더 기다리고 안내합니다.
강제 종료는 사용하지 않습니다. 저장하지 않은 파일이 있으면 Windows가 종료를 막을 수 있습니다.
Windows 종료 명령이 접수된 뒤에는 앱에서 취소할 수 없습니다.

바탕화면과 시작 메뉴 바로가기를 만들려면 create-shortcuts.ps1을 실행하세요.
안전 데모: WindowsTimer.exe --demo (실제 종료 또는 재부팅 명령을 실행하지 않음)
시간 상태 검사: WindowsTimer.exe --self-test (test-results.txt 기록)
